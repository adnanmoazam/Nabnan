NABNAN - free AI assistant and document maker (installable phone app)

FILES (upload ALL of them): index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png

1. GET A FREE AI KEY: open aistudio.google.com/apikey, sign in, tap Create API key, copy it.
2. GITHUB: open your repository github.com/adnanmoazam/Nabnan
   - If an old nabnan.html is there, you may leave it or delete it.
   - Tap Add file > Upload files, choose the 5 files above (unzip this ZIP first), tap Commit changes.
3. TURN ON PAGES: Settings > Pages > Source: Deploy from a branch > main, /(root) > Save. Wait 1-2 minutes.
4. YOUR APP LINK: https://adnanmoazam.github.io/Nabnan/
5. INSTALL ON PHONE: open the link in Chrome > menu (three dots) > Install app (or Add to Home screen).
   iPhone: Safari > Share > Add to Home Screen.
6. FIRST USE: Start > enter your name > gear icon > paste your key > Save.
7. BACKUP: gear icon > Download backup now and then. Chats are stored only on your phone.
8. UPDATING: upload new files with the same names to replace the old ones.
